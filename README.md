# GenAlgLabs

Labs for the Genetic Algorithms course.

## Labs

- [`lab1-maximize-function/`](lab1-maximize-function/) — maximize `f(w,x,y,z) = w³ + x² – y² – z² + 2yz – 3wx + wz – xy + 2` over a bounded domain using a binary-encoded GA.
- [`lab2-tsp/`](lab2-tsp/) — solve the Travelling Salesman Problem with a permutation-encoded GA, using Order Crossover and swap/inversion mutation operators that always produce valid routes.
- [`lab3-gray-code/`](lab3-gray-code/) — convert bit-strings between standard binary and Gray code in both directionsю
- [`lab4-sp/`](lab4-sp/) — find the shortest path from a source vertex to all others, comparing exact Dijkstra against a spanning-tree-encoded GA.
